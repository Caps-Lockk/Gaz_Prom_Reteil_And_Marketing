# Вклад в проект

Для предложения изменений создайте отдельную ветку и pull request. Изменения аналитики должны содержать: описание гипотезы, что меняется в правилах отбора, сравнение метрик на отложенных месяцах, оценку влияния на доли сегментов и тесты.

**Никогда** не добавляйте в pull request исходные `.xlsb`, индивидуальные CSV, псевдонимизированные клиентские ID, токены, скриншоты внутренних систем или сведения о согласиях отдельных пользователей. Используйте `fuel-elasticity demo` и искусственные примеры.

Прежде чем запускать эксперимент с реальными клиентами, нужно согласовать privacy review, правила доступа, бюджет, допустимые каналы и критерии остановки.

Запуск локально:

```bash
python -m pip install -e ".[dev]"
python -m pytest
fuel-elasticity demo --output outputs/demo --clients 1200 --seed 42
```

Лицензия на публикацию кода командой пока не выбрана. Не публикуйте материалы организаторов как собственные; проверьте условия участия.
