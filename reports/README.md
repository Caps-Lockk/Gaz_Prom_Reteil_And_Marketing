# Отчёты

- [`summary.md`](summary.md) — агрегированные результаты на предоставленном XLSB.
- [`summary.json`](summary.json) — те же данные в структурированном виде.
- [`figures/liters.svg`](figures/liters.svg) — суммарные литры по месяцам.
- [`figures/price_gap.svg`](figures/price_gap.svg) — средний разрыв цен.

**Нет** ни исходного `.xlsb`, ни клиентского скоринга, ни таблицы индивидуальных офферов. Для повторного расчёта и обновления отчетов используйте `fuel-elasticity run ...`; скрипт сохраняет новые отчёты в `outputs/`.

Важно: даже агрегированные показатели кейса публикуйте только при соблюдении условий организаторов.
