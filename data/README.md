# Работа с данными

## `raw/` — приватно

Сохраните здесь исходный файл `.xlsb`, полученный от организаторов, **только если у вас есть право на локальную обработку**. В `.gitignore` исключены `data/raw/*`, все `.xlsb`, `.xlsx`, `.npz`, клиентские CSV и папка `outputs/`.

В GitHub публикуются только исходный код, документы, синтетическое демо и **агрегированные результаты, если это разрешено условиями кейса**. Псевдонимизированный ID не означает, что строка автоматически безопасна для публичной публикации.

Команда для запуска приведена в [README](../README.md#-быстрый-старт).
