# Синтетический пример

Не нужен реальный исходный файл. Выполните `fuel-elasticity demo --output outputs/demo --clients 1200 --seed 42` — фиксированный seed создаст искусственные клиентские профили, станции, цены, объёмы и настройки согласий. Генератор: [`src/fuel_elasticity/demo.py`](../../src/fuel_elasticity/demo.py). **Синтетические** результаты не использовать в презентации как результаты на выборке кейса.
