# Ограничения, риски и честная интерпретация

[← На главную](../README.md) · [Методология](methodology.md)

## Что данные действительно позволяют установить

На девяти месячных срезах наблюдается связь между относительной ценой собственной АЗС и объёмом покупок части клиентов. При временном разделении train/holdout ранжирование по коэффициенту сохраняет заметную разницу между выделенными группами.

## Чего данные не позволяют установить

- Что любой отдельный клиент **заправился у конкурента**: продажи конкурентов отсутствуют.
- Что снижение литров вызвано **только ценой**: могут влиять отпуск, переезд, состояние автомобиля, ассортимент, промо, транспортные маршруты и сезонность.
- Что индивидуальный β — структурная ценовая эластичность: используются разницы цен в руб./л и `ln(1+V)`.
- Что персональный кешбэк дал **+5%**: это заданное допущение, A/B пока нет.
- Что предложения можно отправить всем: нужны актуальные согласия, бизнес-ограничения и CRM.

## Качество данных: количественные факты

| Контроль | Наблюдение | Решение |
|---|---|---|
| Период | 9 месяцев | Temporal holdout 7+2; не экстраполировать сезонные закономерности без новых данных |
| Основная таблица | 33 146 уникальных клиентов | Не считать автоматически репрезентативными для всех пользователей программы |
| Нулевой объём | ~13% клиент-месяцев | Оставляем нулевые покупки, не удаляем по факту неактивности |
| Обе цены = 0 | **473** клиент-месяца | Для репликации `gap=0`; это вероятные пропуски, нужна отдельная версия с пропусками |
| Не найден в CRM | **7** клиентов | Нет разрешения на push по умолчанию |
| Цены конкурентов | Средние в окружении | Не доказана доступность конкретной альтернативы каждому клиенту |
| Маржа | Маржа и OPEX отдельно | Выяснить, включает ли средняя маржа OPEX |

## Планы снижения риска

1. С владельцем данных определить значение `0` в полях цен; сравнить сегменты до/после исключения или аккуратного восстановления пропусков.
2. Сравнить 7+2 с перестановкой альтернативных временных окон и проверкой на отдельных регионах/АЗС.
3. Проверить воспроизводимость решения при изменении порогов β, корреляции, активности и LOO.
4. При длительных рядах использовать модель со сглаживанием индивидуальных параметров и контролями за сезонностью, ценами и конкурентной средой.
5. Провести А/B-тест; экономический эффект на пользователя считать на всей рандомизированной аудитории.

Публичные `reports/` содержат лишь агрегаты. Идентификаторы даже в псевдонимизированном виде могут быть конфиденциальными: не помещать их в public-репозиторий.
