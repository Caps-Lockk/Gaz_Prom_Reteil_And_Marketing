# План A/B-теста: доказываем инкрементальный эффект

[← На главную](../README.md) · [Маркетинг](marketing.md) · [Экономика](economics.md)

## 1. Гипотеза

Адресное предложение среди ценочувствительных клиентов при ухудшении относительной цены увеличивает **инкрементальный вклад после бонусов**, а не только долю пользователей, получивших бонус.

## 2. Дизайн

- **Популяция:** отобранные ценочувствительные, активные за последние 3 месяца, с приложением и действующим согласием push; ценовой разрыв превышает порог.
- **Рандомизация:** на уровне клиента, стабильно закреплённая на срок эксперимента, с блокировкой по основной АЗС, виду топлива и базовому объёму. При риске сильного spillover между клиентами одной АЗС рассмотреть рандомизацию станций или геокластеров.
- **Treatment:** персональный бонус на 70 л. **Control:** текущая механика лояльности без дополнительного бонуса.
- **Окно:** задаётся до эксперимента исходя из частоты заправок, бюджетных ограничений и мощности. Не выбирать срок задним числом по результату.
- **Размер выборки:** рассчитывать по дисперсии вкладовой маржи/клиент из исторических данных и MDE, учитывая кластеризацию и повторные измерения. По одной цифре `3 568` автоматически заявить достаточную мощность нельзя.

## 3. Основная метрика

\[
\operatorname{ITT}=\overline{(\text{Вклад после бонусов})}_{Treatment} - \overline{(\text{Вклад после бонусов})}_{Control}.
\]

Используем **всех рандомизированных клиентов**, включая тех, кто не открыл приложение и не заправился. Противопоказано ограничивать расчёт только теми, кто воспользовался бонусом: это создаёт selection bias.

Вклад рассчитывается на одинаковом временном горизонте для групп; затраты на бонусы вычитаются в treatment. Если бонусы доступны и в контрольной группе по другим активностям, их тоже учитывают при расчёте итоговой прибыли.

## 4. Вторичные и защитные метрики

| Тип | Показатели |
|---|---|
| Бизнес | Дополнительные литры на рандомизированного клиента, покупки СТиУ, выручка после удержания, стоимость стимулирования |
| Поведение | Вернувшиеся клиенты, доля активных, повторная заправка в следующие периоды |
| Продукт | Доставляемость push, просмотр предложения, корректность автоматического начисления |
| Защитные | Отписки, жалобы, ошибки списаний/начислений, расход бюджета, снижение маржи |

## 5. Что фиксируем до запуска

1. Момент отбора клиентов, правила заморозки или обновления сегмента.
2. Версию модели, порог цены, пределы скидки, частотные и финансовые лимиты.
3. Метод рандомизации, исключения и анализ перекрытия с другими акциями.
4. Primary metric, MDE, α, мощность и допустимую длительность; критерии остановки по безопасности.
5. Порядок вычисления доверительных интервалов; при кластерной рандомизации учитывать корреляцию внутри кластеров.

## 6. После теста

Если доверительный интервал ITT-прибыли совместим с нулём либо отрицателен — не утверждать, что подход окупился. При положительном устойчивом эффекте расширять географию ступенчато (canary rollout), продолжая держать контроль и отслеживать фоновое изменение цен.
