# Словарь данных и соответствие XLSB

[← На главную](../README.md)

Исходный файл организаторов: `Кейс_Ретейл_и_маркетинг_Дополнительные_данные(1).xlsb`. Файл **не включён** в репозиторий и не должен публиковаться без разрешения правообладателя.

| Лист | Поля | Использование |
|---|---|---|
| **Данные** | Клиент; Основная АЗС заправки; Топливо; по девять месяцев: литры, собственная цена, цена конкурентов | Главная панель «клиент × месяц» |
| **Информация об АЗС** | АЗС; Тип АЗС; Тип управления; Формат; Время работы; Подразделение; Сегмент расположения | Присоединяем `Подразделение` как региональную группу |
| **Информация о клиентах** | ID_KLIENTA; замаскированные даты; согласия email/SMS; наличие приложения; статус карты; согласие push | Отбор кандидатов на коммуникации |
| **Покупки сопутствующих товаров** | ID; число месяцев, число чеков, выручка брутто и нетто | Описательный cross-sell (не включён в топливную маржу) |
| **Маржа** | НГ; Регион; Средняя маржа руб/т; Средний OPEX руб/т | Вклад на литр после OPEX при заданном допущении |
| **Плотность** | НГ; Плотность (т/м³) | Перевод тонны топлива в литры |

**Формат блока «Данные»:** 30 столбцов: 3 ключа + 9 объёмов + 9 цен сети + 9 цен конкурентов. Первые две строки — заголовки групп, третья — ключи и месяцы. Скрипт проверяет совпадение последовательностей месяцев в блоках.

## Выявленные особенности исходника

- **33 146** уникальных строк с клиентами в основной таблице, **642** уникальные основные АЗС; справочник АЗС шире фактически наблюдаемых основных станций.
- **7** клиентских ID не найдены в CRM; при отсутствии сведений о каналах все согласия для них считаются отсутствующими.
- **473** парных нуля в полях цен компании и конкурентов. Это похоже на пропуски, но не доказано; нужно запросить у владельца данных точную семантику. Для репликации текущей исследовательской сводки `0 − 0 = 0`.
- Показатели по сопутствующим товарам представлены суммарно за период; нельзя автоматически присваивать им инкрементальный эффект акции.
- Псевдонимизированные обозначения городов/регионов **не следует интерпретировать как реальные места расположения АЗС**.

## Политика хранения

`data/raw/` — только на локальном компьютере или в согласованном закрытом хранилище. Результаты индивидуального скоринга — в `outputs/private/`. В `reports/` — только агрегированные показатели и графики (их публикацию также требуется согласовать с владельцем данных). Список исключений находится в `.gitignore`.
